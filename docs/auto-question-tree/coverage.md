# Покрытие исходного справочника

Проверено: 394 работ из 25 систем и 57 подразделов; по одной записи и одной строке на пункт третьего уровня. Названия сохранены вместе с пунктуацией; переносы строк источника соединены пробелом.

Прямой вход: «Нужна услуга: …» → id работы. Бытовой вход в таблице означает жалобу/неопределённость → диагностику с компетенцией соответствующего раздела. Он не подтверждает ремонт из этой строки. Для явного желания установки, ухода, доставки и хранения достаточно уточнить результат и выбрать известную услугу; диагностика не обязательна. Объединённые диагностико-ремонтные услуги по жалобе означают только диагностический этап.
