# Оборудование и смежные обращения

Разделы 14–25. Все работы доступны через общий direct. Неопределённые желания сначала проходят intent: желание само по себе не означает неисправность. Чужое заключение не доказывает симптом или неисправность. Все сценарии — ручное проигрывание графа без запуска бота. Число вопросов не включает известное родителю направление.

Общие слоты наследуют slots.json. Исправление заменяет активное наблюдение с сохранением истории. Несколько жалоб объединяют результаты.

## Проверка экспертом

- Граница диагностики питания при разрядке и общей проверки: не исключать другие причины.
- При ошибке после замены стекла ADAS направляется на диагностику; необходимость калибровки определяет изготовитель.
- Запах газа: местные правила срочности и способ передачи профильному исполнителю требуют отдельного экспертного протокола; дерево не даёт проверок пользователю.
- Уменьшение запаса хода не доказывает дефект батареи; проверить достаточность маршрута оценки батареи и необходимость общей диагностики.
- При ударе/воде у электромобиля дополнительно нужен экспертный протокол ближайшего действия, без самостоятельных проверок HV.
- Сигнализация может быть нештатной: при неизвестном типе сохранять обе компетенции, не обещать диагностику только штатного доступа.
- Пятна/изменения покрытия: определить с экспертом границу осмотра и известной услуги ухода.
- Перевозка не катящегося автомобиля: диспетчер подтверждает оснащение; неизвестное состояние не считать способностью катиться.
- Проверить доступность коммерческого транспорта проекту; при отказе не обещать исполнителя.
